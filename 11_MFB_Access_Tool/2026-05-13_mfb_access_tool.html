Problem Statement

Rehab liaisons generate dozens of coordination communications weekly — transfer readiness notifications, insurance auth follow-ups, admission confirmations, and denial letters. Each type targets a different recipient, requires different clinical elements, and triggers a different action chain. Drafting from scratch is slow, inconsistent, and risks omitting critical details.

Testing Checklist

  • All 6 types generate unique, complete, non-overlapping templates
  • Clinical flags populate correctly in all 6 output paths
  • Urgency pill: green (routine) / yellow (urgent) / red (emergent)
  • Auth fields appear only when Auth Follow-Up is selected
  • Copy-to-clipboard toast fires and dismisses after copy
  • Reset clears all fields and hides output panel
  • Print: buttons hidden, output area fully expanded, colors preserved
  • PHI banner visible at all screen widths
  • Mobile <768px: columns stack, all controls remain usable
  • No data in localStorage or sessionStorage after reset
  • Placeholder text visible when no template has been generated
  • Long "Action Requested" text wraps cleanly in output area

Next Iteration Ideas

  2. Session history (no PHI) — track template types generated in current session for workflow analytics
  3. Multi-language patient-facing variants — Spanish admission confirmation and arrival instructions
  4. PAS Calc integration (Tool 1 → Tool 8) — auto-populate FIM tier from Week 1 PAS score tool

  6. Regulatory compliance flags — auto-add CMS PASRR / discharge notice language for applicable types
