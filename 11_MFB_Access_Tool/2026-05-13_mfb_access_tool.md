---

## Problem Statement

Rehab liaisons generate dozens of coordination communications weekly — transfer readiness notifications, insurance auth follow-ups, admission confirmations, and denial letters. Each communication type targets a different recipient, requires different clinical elements, and triggers a different action chain. Drafting from scratch is slow, inconsistent, and risks omitting critical clinical or operational details. Copy-paste from prior notes introduces stale language and wrong placeholders.

## Next Iteration Ideas

1. **Payer-specific language variants** — auto-adjust auth follow-up language by payer type (Medicare, Medicaid, commercial HMO, workers' comp) to match their preferred terminology
2. **Session history (no PHI)** — track template types generated in the current session for workflow analytics without storing any patient data
3. **Multi-language patient-facing variants** — Spanish-language admission confirmation and arrival instructions for patient/family copy
4. **PAS Calc integration (Tool 1 → Tool 8)** — auto-populate functional status tier from PAS score generated in the Week 1 tool
5. **Escalation chain visualizer** — embedded flowchart showing who to contact next and when if no response is received within the urgency window
6. **Regulatory compliance flags** — auto-add CMS PASRR / Stark Law / discharge notice language for applicable communication types
