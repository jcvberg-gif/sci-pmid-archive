Problem Statement

Cervical SCI patients appear across acute, inpatient rehab, and outpatient settings with potential eligibility for ARC-EX tSCS — but without a structured screener, candidacy is evaluated inconsistently, referrals are delayed, and documentation is incomplete. This tool provides fast, criteria-aligned screening that ends in a copy-paste Epic note block.

Screening Logic

✓ CANDIDATE
All 5 core inclusion criteria met • No absolute exclusions • No unresolved relative exclusions
⚠ CONDITIONAL
Subacute timing • Relative exclusion present • Caregiver/transport barrier • Prior e-stim intolerance
✗ NOT A CANDIDATE
Absolute exclusion present • Missing core inclusion • Age <18 • Thoracic+ SCI • Acute injury (<1 mo)

Epic SmartPhrase Pairing

Suggested name: .MFBARCEX

The "Copy as Epic SmartPhrase" button copies a pre-formatted note block. Paste directly into H&P, Rehab Progress Note, or SCI Consult. Output includes: injury profile • inclusion criteria met • exclusion criteria present • candidacy determination • numbered next steps • contextual support factors.

Testing Checklist

1T1+ injury level → verdict = NOT a candidate, thoracic SCI reason displayed
2Pacemaker exclusion alone → NOT a candidate
3All 8 inclusions checked + C5–C6 / AIS C / >12 months / adult + no exclusions → CANDIDATE
46–12 months post-injury without ≥6mo inclusion checked → CONDITIONAL
5Uncontrolled AD (relative) with otherwise clean profile → CONDITIONAL
